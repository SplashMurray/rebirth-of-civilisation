# Security

Rebirth of Civilisation is an offline single-player game. It makes no network connections and reads only its own saved games.

Official downloads come only from this repository's [Releases page](https://github.com/SplashMurray/rebirth-of-civilisation/releases) and are built by GitHub Actions. See the [Code signing policy](CODE_SIGNING_POLICY.md) for how releases are built and signed.

To report a security problem, such as a crash caused by a malformed save file, or a download that does not match this repository, please open an issue. If it is sensitive, use GitHub's private vulnerability reporting under the repository's **Security** tab.
